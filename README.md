# Измерение скорости скачивания

Консольный скрипт на Python, который измеряет скорость скачивания по заданному адресу.

Скрипт делает 10 последовательных запросов к адресу, каждый раз дожидаясь полного ответа, и выводит:
- время каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Требования
к
- Python 3.8 или новее
- Сторонние библиотеки не нужны (используется только стандартная библиотека)

## Запуск

```bash
python speedtest.py "<ссылка>"
```

Ссылку лучше брать в кавычки, иначе символы `&` и `?` могут сломать команду в терминале.

Пример:

```bash
python speedtest.py "https://fydi.ru/wp-content/uploads/2024/09/fydi_ru-1.webp"
```

Для точного замера используйте крупный файл (от нескольких мегабайт), например:

```bash
python speedtest.py "https://proof.ovh.net/files/10Mb.dat"
```

## Пример вывода

```
Запрос 1: 0.84 с, 10.49 МБ
Запрос 2: 0.79 с, 10.49 МБ
...
Запрос 10: 0.81 с, 10.49 МБ

Успешных запросов: 10 из 10
Среднее время запроса: 0.82 с
Всего скачано: 104.86 МБ
Скорость скачивания: 102.31 Мбит/с
```

(значения в примере условные, у вас они будут другими)

## Единицы измерения

- Скорость выводится в **мегабитах в секунду (Мбит/с)**, где 1 Мбит = 1 000 000 бит.
- Объём данных выводится в **мегабайтах (МБ)**, где 1 МБ = 1 000 000 байт.
- Время выводится в секундах.

## Как считается скорость

Скорость = (общее число скачанных байт × 8) / (суммарное время всех запросов) / 1 000 000.

Время каждого запроса измеряется от отправки запроса до полного получения тела ответа.

## Допущения

- Запросы выполняются строго последовательно.
- Если запрос завершился ошибкой (нет сети, статус не 2xx, таймаут 30 секунд), он выводится как ошибка и не учитывается в статистике. Среднее считается по успешным запросам.
- Каждый запрос устанавливает новое соединение, поэтому в замер входит и время его установки.
